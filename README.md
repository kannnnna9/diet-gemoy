# Diet Gemoy

App companion program diet pribadi untuk **paypey** (suami) & **ffazeyall** (istri).

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Fase

- **Fase 1** (selesai): 100% lokal, data di localStorage + IndexedDB. Nol backend, nol kredensial.
- **Fase 2** (menyusul): Supabase sync, login 2 akun, Google Tasks CTA.

## Stack

Vite + Vue 3 + Pinia + vue-router (hash mode). Font: Fraunces (heading) + Quicksand (body). Ikon: Lucide.
